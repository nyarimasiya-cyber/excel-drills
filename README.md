# Excel Analyst Drills

Hands-on Excel practice for analyst roles: training notes for 10 topics plus 52 exercises covering core and date formulas, dynamic arrays, lookups, tables and names, LET and LAMBDA, Power Query, DAX and VBA.

Live site: https://nyarimasiya-cyber.github.io/excel-drills/

Everything runs in the browser (`index.html`); no server or sign-in is needed. Progress is saved in each person's own browser.
